隱私權政策

最後更新：2026 年 9 月 29 日

本政策說明「憤怒的邦基」網站及遊戲如何處理資料。遊戲本身以瀏覽器本機執行；目前沒有遊戲帳戶、雲端存檔、線上排行榜、廣告或分析追蹤程式。

1. 遊戲在你的裝置上保存的資料

遊戲會使用瀏覽器的 localStorage，在目前瀏覽器及網站來源下保存遊戲設定、戰役紀錄，以及無盡挑戰的波次存檔、成績、成就和外觀解鎖。這些資料用於保留你的偏好與遊戲進度；遊戲程式不會將它們傳送至遊戲伺服器。

你可以在瀏覽器設定中清除此網站的儲存資料。清除後，本機設定、紀錄及存檔可能無法復原；封鎖本機儲存功能時，遊戲仍可遊玩，但資料不一定能保留。

2. 網站託管與連線資料

本網站由 GitHub Pages 託管。載入網頁及遊戲素材時，瀏覽器會向 GitHub 的伺服器提出請求；GitHub 可能依其政策處理連線所需的技術資料（例如 IP 位址、請求時間及瀏覽器資訊）。這些屬於託管平台的處理，並非遊戲讀取或保存的玩家個人檔案。詳情請參閱 GitHub 隱私權聲明。

3. 在 Discord 中使用

若你在 Discord 內開啟本遊戲，Discord 會依其政策處理帳戶、裝置及 Activity 使用資料。現行遊戲不會透過 Embedded App SDK 讀取或接收你的 Discord 身分、好友、伺服器成員或參與者資料；若日後加入相關功能，本政策會相應更新。請參閱 Discord 隱私權政策。

4. 音訊、圖片及第三方服務

遊戲素材由本網站提供；音效由瀏覽器即時合成，背景音樂僅在你啟用並與頁面互動後播放。遊戲不會使用麥克風或攝影機，也不會藉此收集生物特徵資料。

5. 未成年人

本遊戲不是為收集個人資料而設計。請遵守你所在地對使用網路服務的年齡要求，以及 Discord 等平台適用的年齡規定。

6. 政策更新與聯絡

本政策更新後會刊載於本頁並更新日期。若對資料處理有疑問，請透過 GitHub 專案問題頁聯絡。該問題頁是公開的；你提交的內容及 GitHub 帳號名稱可能對外可見，並由 GitHub 依其政策處理。
